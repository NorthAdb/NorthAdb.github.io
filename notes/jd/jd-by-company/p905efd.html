岗位1: 世界模型算法工程师（北京）| 北京市 | 校招（拓疆者2027）

链接: https://apply.careers.dji.com/campus-recruitment/dji/143359?locale=zh-CN#/job/e6526e0a-a65a-43c3-883d-52ae29182798

职位简介
大疆飞行系统部正在为飞行场景构建"可控生成式数字孪生"——以数百万真实飞行片段为原料，从大规模 3DGS/4DGS 重建、可控视频生成、场景编辑，到 log2world 训练闭环与强化学习仿真，我们具备完整技术栈。我们寻找相信"世界模型是数据飞轮底层引擎"的同路人，与我们一起，把真实物理世界以可生成、可分支、可重放的方式带入训练循环，让世界模型成为新一代具身智能的"梦境引擎"。

工作职责
1. 负责基于多视图/时序传感器的大规模 3D/4D 场景重建与新视角合成算法研发；
2. 负责可控视频生成与场景编辑算法，支撑长尾场景仿真与真实数据的可控扩展；
3. 负责仿真平台与训练链路的算法侧集成，支撑数据合成与强化学习训练闭环；
4. 跟进世界模型/神经渲染/生成式仿真方向的前沿进展并在业务中落地。

任职要求
基本要求
1. 计算机、电子、自动化、图形学等相关专业，硕士及以上学历；
2. 扎实的三维视觉、神经渲染或生成模型基础，熟练 PyTorch/CUDA；
3. 在以下方向至少一项有深入实践：3DGS/4DGS/NeRF/神经隐式表征、Diffusion/视频生成、可控生成与场景编辑、Driving/Embodied World Model；
4. 具备大规模数据处理与训练能力，能独立完成"重建-生成-评测"链路。

加分项
1. SIGGRAPH/CVPR/ICCV/ECCV/NeurIPS/ICLR 等顶会一作论文；
2. 复现或主导过 Sora/Cosmos/GAIA/DriveDreamer/Vista/WorldDreamer/Genie 等世界模型类工作；
3. 熟悉 Nerfstudio/gsplat/Threestudio/Diffusers 等开源框架并有核心贡献；
4. 有真实机器人、自动驾驶或无人机数据的 log2world、sim-to-real 实战经验。

岗位2: 空间智能 OS 工程师（上海）| 上海市 | 校招（拓疆者2027）

链接: https://apply.careers.dji.com/campus-recruitment/dji/143359?locale=zh-CN#/job/c688765c-8541-42a6-9edf-fb23849e65fc

职位简介
该职位为嵌入式中操作系统OS方向，包括底层驱动、操作系统优化、中间件。聚焦如何提升基础技术从而对产品带来指数级提升。
你将加入大疆空间智能 OS 核心团队，负责嵌入式系统内核、硬件抽象层以及分布式系统中间件的架构设计与开发。
不同于通用操作系统开发，你将面向飞行器高速机动、高空复杂环境、极限温变、高可靠与安全冗余等严苛场景，构建支撑大疆全系空间智能硬件的统一系统底座。
作为公司最核心的 OS 嵌入式岗位之一，你搭建的系统底座将承载飞行智能、影像能力、端侧 AI 能力等核心功能，是保障大疆产品稳定、安全、高效运行的关键基础。

工作职责
1. 负责大疆实时操作系统内核迭代，优化任务调度、内存管理、中断实时通路、多核协同机制，持续提升机载平台的实时性、稳定性与安全性；
2. 搭建机载整机硬件抽象架构，完成SoC、机载传感器、云台、图传等定制硬件的统一适配与封装，实现软硬件解耦，支撑多产品线快速迭代；
3. 研发面向空间智能飞行机器人的分布式中间件体系，包含整机高速通信总线、资源管理、状态调度、故障诊断、日志追踪等通用基础组件；
4. 针对机载极限工况开展系统功耗、时延、稳定性专项优化，建立大疆专属机载系统性能标准体系；
5. 向上层影像应用、AI算力引擎提供稳定、标准化的底层系统接口，支撑全业务高效迭代。

任职要求
1. 本科及以上学历，计算机、电子、通信、自动化、车辆工程或软件相关专业优先；
2. 熟悉C/C++编程语言，具有良好的代码编写习惯；
3. 具有扎实的数字电路、模拟电路、微机原理等专业理论基础知识，能够看懂原理图，熟悉ARM/DSP等任一平台的体系架构，熟悉一种及以上常用外设接口，如USB/UART/I2C/SPI/CAN/SD/BLE/MIPI/以太网/I2S/PDM等；
4. 至少具有以下条件之一：
① 熟悉Linux/RTOS内核，熟悉内存管理、线程、任务调度、中断管理和存储等模块，具有驱动开发或者应用开发经验；
② 熟悉Linux网络驱动和协议栈，有无线网卡、BT等驱动开发经验；
③ 熟悉DSP或NEON代码优化，熟悉vector C或 intrinsic C编程；
④ 熟悉无刷直流电机、永磁同步电机基础控制原理，有相关驱动器开发经验，熟悉dSPACE/MBD等开发方式；
⑤ 熟悉大功率电源，逆变器、DC/DC、buck、boost等电源拓扑，有相关电源产品调试经验；
5. 具有较强的学习、沟通表达能力和良好的团队合作精神；
6. 具有无人机、机器人开发经验或有RoboMaster/ROBOCON比赛经验、各类电子设计竞赛经验者优先。

岗位3: 大前端开发工程师（北京）| 北京市 | 校招（拓疆者2027）

链接: https://apply.careers.dji.com/campus-recruitment/dji/143359?locale=zh-CN#/job/9318543d-f926-40a6-8732-9ab0c50b5ff2

职位简介
我们致力于把大疆设备和大疆用户紧密相连，"让机器有温度，让数据会说话"是我们的核心使命。

工作职责
1. 负责的业务方向包括但不限于：DJI Mimo、DJI Studio、DJI Fly、行业Pilot、行业生态SDK、大疆农服等；
2. 负责 DJI 软件在智能手机、Pad、PC端或自研终端设备上的应用程序开发和技术实现；
3. 负责 DJI 纯软 Agent、软硬协同 Agent 的开发工作。

任职要求
1. 本科及以上学历，计算机相关专业；
2. 了解大前端主流框架中的一种或多种；
3. 有大前端工程化经历，了解前端开发测试发布上线整体流程；
4. 具备良好的团队沟通与协作能力，熟悉项目管理，敏捷开发流程，能够持续关注前端新的技术方向，具有良好的学习能力和进取心，较强的责任心。
