官网: https://hr.sensetime.com/（sensetime.com/cn/careers 404；校招投递页: https://hr-jobs.sensetime.com/edu/，校招实习岗 162 个）

岗位1: 多模态大模型实习生-深圳 | 深圳市 | 实习（校招实习·研发-算法）

链接: https://hr-jobs.sensetime.com/edu/position/7670437248752601386/detail

职位描述
* 参与大模型应用落地，理解业务侧算法需求，用多模态大语言模型将其实现并持续优化性能指标；
* 提升多模态大模型在现实世界复杂任务的效果，追求通用可规模化的方法，优化领域包括但不限于视觉推理、多模态Agent、专业领域数据合成等方向；
* 设计与优化智能体的workflow。

任职要求
* 计算机、电子工程、统计学等专业的本科及以上学位在读学生；
* 扎实的专业基础和项目经历，优秀的问题分析和解决能力，熟悉CV、AIGC、NLP、RL等技术领域，在CVPR、ECCV、ICCV、NeurIPS、ICLR等顶级会议上发表论文者优先；
* 优秀的沟通能力和团队合作意识。

岗位2: 存储系统开发实习生 | 北京市 | 实习（校招实习·研发-后端开发）

链接: https://hr-jobs.sensetime.com/edu/position/7670484036763158830/detail

职位描述
1. 负责存储管理面功能的开发和维护，主要涉及，对象存储管理面，文件存储管理面，块存储管理面等。
2. 负责技术文档撰写,实现云平台业务功能整合。
3. 负责迁移工具ADS的开发和维护。
4. 负责排查存储管理面线上问题和性能优化。

任职要求
1. 本科及以上学历，计算机等相关专业（2027届硕士优先，历史实习转正比例较高）。
2. 有 C++ / Golang 使用经历，良好的coding，debug能力。
3. 了解主流云存储服务，包括但不限于对象存储，文件存储等。
4.了解k8s，容器等云原生技术。
5. 熟练使用 AI 工具进行快速迭代开发。

岗位3: 训练推理优化实习生，多模态 | 北京市 | 实习（校招实习·研发-后端开发）

链接: https://hr-jobs.sensetime.com/edu/position/7670103435232921899/detail

职位描述
1. AIGC研究与工程探索
· 深度参与商汤开源lightx2v引擎（https://github.com/ModelTC/LightX2V/）的社区核心模块开发与调优。
· 跟踪视频/图像生成及LLM推理的前沿技术趋势，将学术界最新成果转化为引擎的实际性能增益。
· 协助头部客户快速完成业务落地，形成规模化应用效应。
2. 模型性能剖析与国产化深耕
· 熟练分析训练推理过程中的性能瓶颈。
· 基于国产算力（沐曦、寒武纪等）生态，开展算子级深度优化与工具链整合，解决精度对齐、算子性能不足等国产化迁移痛点，为客户提供平滑迁移的端到端保障。

任职要求
1. 计算机、人工智能、数学等相关专业在读硕士、博士。
2. 熟练掌握 C++ 和 Python 语言。
3. 有扎实的计算机基础知识，熟练掌握常见的数据结构和算法。
4. 具备 AI 辅助编程实践经验，能够熟练使用 Codex、Claude Code、Cursor等 IDE 编程助手，并能够将其应用于实际研发场景提升开发效率。
加分项
1. 对AI大模型相关核心技术原理有认知，熟悉sglang、vllm等大模型框架，有训推性能优化经验。
2. 熟悉视频和图像生成（x2v），熟练运用Stable Diffusion、ComfyUI、Midjourney等工具链，掌握lightx2v等推理框架。
3. 熟悉国产算力（沐曦、寒武纪等）生态与软件栈，具备算子适配、性能调优及精度对齐的实操经验。
4. 有高性能网络 (rdma/ib/roce) 相关的经验。

岗位4: 容器网络实习生，控制面+数据面 | 北京市，上海市 | 实习（校招实习·研发-后端开发）

链接: https://hr-jobs.sensetime.com/edu/position/7670428288498190655/detail

职位描述
1. 参与云容器网络控制面服务产品功能设计。
2. 参与数据面模块代码开发、单元测试。
3. 参与完善 CI/CD 流程，加快开发迭代速度。

任职要求
1. 计算机、电子、通讯相关专业的在读本科生或研究生，2027届优先考虑（历史实习转正概率大）。
2. 有较好的计算机基础知识、Linux 系统原理和网络相关知识。
3. 熟悉至少一种编程语言，如 Golang、Python、C++ 等，熟悉一种脚本语言，如 Shell 或者 Python。
4. 对 Docker、Kubernetes、OVS 等容器化技术和容器网络有一定的了解，有相关的实践经验者优先。
5. 熟悉 Linux 操作系统和基本的命令行工具，了解 TCP/IP 协议和网络编程。
6. 思维缜密，逻辑性强，沟通能力强，良好的团队协作精神。

岗位5: Web全栈开发工程师，偏前端 | 北京市 | 实习（校招实习·研发-前端开发）

链接: https://hr-jobs.sensetime.com/edu/position/7670828682361997594/detail

职位描述
1. 负责部门业务涉及的 PC 端 Web 管理台、官网、运营后台、以及 H5、微信小程序等项目的开发维护工作。
2. 在导师的带领下，与产品、UED、后端开发配合，高效高质量的完成 Web 端开发工作。
3. 调研前端技术方案，为产品功能及交互提出专业可靠的建议。
4. 积极探索并实践任意AI 辅助编程工具，用于提升代码编写、调试及文档生成的效率。

任职要求
1. 本科及以上学历在读，2027届优先（历史实习转正率较高）。
2. 3 个月以上 Web 端开发实习经验，或个人项目经验。
3. 熟悉 HTML/CSS/JavaScript  等前端技术，熟悉 JS 运行基本原理，熟悉任一前端框架运行基本原理。
4. 了解各种 Web 标准，了解各主流浏览器特性。
5. 了解模块化、组件化方式开发前端页面，能够利用 RxJS 组织复杂数据流。
6. 熟练使用类 Unix 系统（各种 Linux 及 Mac OS ）。
7. 具备良好的合作态度和团队精神，乐于学习，工作有激情，富有责任感。
8. 每周实习 4 天以上，连续实习期 6 个月以上。
9. 熟练使用主流 AI 编程助手，具备优秀的 Prompt Engineering（提示词工程）能力，能甄别 AI 生成代码的准确性与安全性，并进行有效的重构与优化，有利用 AI 工具解决实际开发（如SQL 生成等）的经验。
加分项
1. 在读硕士优先。
2. 熟悉 node.js 或 Typescript 者优先。
3. 有技术博客或开源项目者优先，可在简历附上相关地址。
