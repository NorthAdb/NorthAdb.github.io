岗位1: 快手后端实习生（AI方向）-【主站】| 北京 | 日常实习

链接: https://zhaopin.kuaishou.cn/#/official/trainee/job-info/31928

职位描述
1、参与快手核心产品需求的分析、技术方案设计及代码开发，直面高并发、海量数据的工程挑战；
2、负责或协助消费业务场景下的AI应用研发，包括但不限于：Agent智能体开发、提示词/上下文工程、模型选型与调优；
3、推动AI技术在具体业务中的落地，探索提升用户体验与业务效率的技术方案。

任职要求
1、本科及以上学历，2027届毕业生优先；
2、具备扎实的计算机基础和编程能力，了解多线程、网络编程；对常见分布式中间件有认知；能使用Linux进行基础开发运维；
3、理解大模型基本原理，对AI应用开发（如Agent、提示工程、微调）有浓厚兴趣或实践经验者优先；
4、具备优秀的学习能力、逻辑思维和主动沟通意识，乐于团队协作。

岗位2: （可灵 AI 专项）AIGC Agent 系统开发实习生 | 北京 | 日常实习

链接: https://zhaopin.kuaishou.cn/#/official/trainee/job-info/27069

职位描述
1、参与可灵 AIGC 生态产品矩阵的应用设计、开发与优化；
2、负责跟进和探索AI Agent领域最新的技术和趋势，结合具体业务场景，给出工业化落地方案；
3、设计并实现高性能、高并发、高可用的系统架构，解决海量多媒体数据处理、模型推理等工程挑战，持续优化系统性能与稳定性。

任职要求
1、预计2026或之后获得本科及以上学历，计算机、软件工程、人工智能等相关专业优先；
2、计算机基础扎实，熟练掌握Java/Python/C++/TypeScript/JavaScript中至少一门语言，有服务端系统的开发经验；
3、聪明好学，有较强的自驱力和学习力，良好的沟通协作能力；
4、有以下经验者优先：
1）具备 AIGC 产品、Agent 产品或其他垂直领域 AI 产品的工程开发经验；
2）有计算机视觉（CV）或多媒体处理（FFmpeg/OpenCV）类项目的开发经验。

岗位3: AI Agent 研发工程师 - 实习生 | 北京 | 日常实习

链接: https://zhaopin.kuaishou.cn/#/official/trainee/job-info/28432

职位描述
1、负责大模型平台的技术研发，包括Multi-Agent框架、Memory机制、RAG、Prompt等基础能力建设；
2、深入研究和开发 Agent框架，优化框架的性能、可扩展性和稳定性，以支持大规模、复杂的多智能体系统应用；
3、设计和实现高效的上下文机制，确保大模型能够有效地存储和检索信息，提高模型的学习和推理能力；
4、研究和应用RAG（检索增强生成）技术，结合外部知识源，提升大模型的生成质量和准确性；
5、探索和优化Prompt技术，设计合适的提示策略，引导大模型生成更符合需求的输出；
6、与团队成员紧密合作，共同推进大模型平台的技术创新和产品迭代；
7、持续关注并跟进业界技术发展，比如 Agent 智能化演进、上下文智能化管理、Agentic AI等方向。

任职要求
1、本科及以上学历在读，计算机相关专业优先；
2、掌握常用数据结构与算法，具备扎实的编程基础和良好的编码习惯；
3、熟悉至少一种编程语言（如 Golang、Java、Python 等）；
4、对大模型有深入理解，熟悉LLM技术原理与应用方法，有Agent系统设计与实现经验；了解Memory机制、RAG、工具调用、规划执行等Agent关键技术，有相关实践经验；
5、积极主动，自驱力强，具备良好的团队合作精神和解决问题的能力；
6、深入理解Agent相关技术方法，具备强化学习、规划算法实践经验者加分；
7、对AI原生应用有强烈热情，具备快速复现论文及工程化能力，顶会论文或开源项目贡献者加分。

岗位4: 大模型应用算法实习生（Agent方向）| 北京 | 日常实习

链接: https://zhaopin.kuaishou.cn/#/official/trainee/job-info/25662

职位描述
1、了解大语言模型及多模态大模型的微调、prompts调优、指令构建与优化，负责将LLM落地在AIGC产品上；
2、负责LLM及多模态大模型的应用相关技术研究，包括但不限于Agents 、RAG、 MCP、prompt工程等，探索大模型应用前沿及新兴应用场景；
3、负责agents相关基础组件的建设，如上下文记忆、deep research、workflow 等，并针对业务需要研发相关的工具集合；
4、了解业务，与公司各技术团队密切配合，能与产品、运营等角色高效沟通需求和目标，发挥自己的主观能动性，设计技术解决方案。

任职要求
1、硕士及以上学历，计算机、人工智能、数学相关专业；
2、有较强的工程实现能力，熟悉LLM及MLLM基本原理、大模型微调/RLHF等后训练技术，熟悉C/C++、Python、Java等至少一门主流编程语言；
3、对NLP、CV、KG、GNN、AI infra 等相关领域有深入的理解，且有相关实际项目经验加分；
4、对学术前沿工作有浓厚兴趣，并善于利用各类技术解决复杂的实际问题，在顶级学术会议上发表过论文加分；
5、有ACM / Kaggle等竞赛相关经验加分。

岗位5: AI Agent算法实习生（智能创作）-【可灵AI专项】| 北京 | 日常实习

链接: https://zhaopin.kuaishou.cn/#/official/trainee/job-info/31530

职位描述
我们正在寻找优秀的你，参与下一代智能内容创作Agent系统的核心能力研发与产品化落地。核心职责包括：
1、负责智能创作Agent与AI内容生产模型的设计与优化，基于大语言模型、多模态模型和视觉生成模型，构建具备自主规划、多步推理、工具调用、长短期记忆、RAG 增强、多Agent 协作及复杂 Workflow 编排能力的内容创作系统，覆盖剧本创作、分镜生成、角色设定、视频生成、内容编辑等复杂内容生成流程，持续提升生成效果、可控性与一致性；
2、负责 AIGC 图像与视频生成算法研发，包括图像和视频生成与编辑、条件控制生成等方向，推动生成模型在内容创作场景中的规模化落地；
3、探索基于Agentic RL的下一代理解、规划、生成、编辑一体化的智能创作模型；
4、与产品、工程团队协同，沉淀可复用的创作Skill、Workflow与评测体系，通过数据回流持续优化核心指标。

任职要求
1、硕士及以上学历，计算机、人工智能、数学、电子信息等相关专业优先；
2、精通 Python，具备扎实的 C/C++/Go/Java（至少一门）基础，具备优秀的软件工程能力与系统设计能力，追求高质量代码实现；
3、深入理解Transformer架构及生成式模型原理，熟悉 PyTorch等深度学习框架，掌握机器学习、强化学习、计算机视觉、自然语言处理等相关基础理论；
4、熟悉主流 AIGC与多模态生成技术，包括但不限于Stable Diffusion、ControlNet、LoRA、视频生成与编辑等相关方向；
5、深入理解 Agent核心范式，包括Planning、Reasoning、Tool Use、Memory、RAG、Workflow、Multi-Agent 等，熟悉 MCP、Function Calling、Structured Output 等Agent 生态技术；
6、具备极强的学习能力与技术热情，对Agent、AGI 与 AI Native 应用方向有浓厚兴趣，逻辑清晰，具备良好的沟通协作能力与独立推进复杂项目的能力。

加分项：
1、在 NeurIPS、ICML、ICLR、ACL、CVPR、ICCV 等顶级会议发表过论文；
2、在 ACM-ICPC、NOI/IOI、TopCoder、Kaggle 或知名AI 算法竞赛中获得优异成绩；
3、为知名开源项目核心贡献者，或在开源社区具备较强影响力；
4、有 LangChain、AutoGen、MetaGPT、OpenClaw、Hermes Agent 等 Agent Framework / Runtime 的使用或二次开发经验；
5、有 RLHF/RLVR、Reasoning Model、Agent Fine-tuning、大模型Post-training 等相关经验优先；
6、有AI Native 产品、AI Agent 平台或企业级 Agent Workflow的 0-1 构建经验优先。
