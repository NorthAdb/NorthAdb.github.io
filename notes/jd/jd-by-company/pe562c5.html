官网: https://careers.kimi.com/（www.moonshot.cn/careers 为 nginx 默认页；招聘系统为 Moka） 说明: 含校招（全职）与实习岗位

岗位1: Kimi Agent Eval 研究与产品实习生 | 北京市 | 实习

链接: https://app.mokahr.com/campus-recruitment/moonshot/148507?sourceToken=36ae0fe79b871e0600f2b2cfe0a81ebb#/job/47f1dc78-543f-43ba-b320-da601590f8d6

职位描述
如果你相信Agent的价值不止步于榜单高分，而是真正解决专业领域的复杂问题
如果你已经把 Agent 用进自己的真实工作，探索或思考过它的能力边界
—— 我们邀请你带着好奇心与判断力，一起定义智能的尺度。

岗位职责
定义专业领域的 Agent 能力标杆：作为某个垂直专业领域的深度用户，亲自定义 Agent 在该领域的SOTA标准，设计高难度的题目与verifier 挑战能力边界
将人类SOTA产物转化为优质的题目与训练数据：探索并搭建一套通用、规模化的"专家成果 → 结构化评测任务"pipeline，将非标与隐性的经验，提取为可运行、可复现的benchmark与数据
构建专家评估平台产品：从0到1定义Agent评测平台产品，设计并优化人机协作流程，推动关键环节的自动化与工具化

任职要求
在某一个科学或专业领域有扎实的积累（如生物信息学、计算物理/化学、神经科学、医学等），有物理、生物、化学竞赛经验的优先
在科研/实习中使用过agent产品解决该专业领域的实际问题、或搭建工具以提升工作效率
实习时间至少 4 个月，每周至少 4 天，Base 北京。

你将收获
稀缺复合经验：同时积累"领域专业深度 × 工程化Pipeline × Agent Evaluation"的交叉能力
高效的self evolving：有机会独立负责完整模块，与RL团队紧密协作，建立更本质的evaluation
深度参与 Agent 评测基础设施建设，动手打造一个出色的平台产品
投递邮箱：tracy@moonshot.ai
投递标题：Kimi Agent Eval-姓名-学校-专业

岗位2: Agent Development Engineer（实习）| 北京市 | 实习

链接: https://app.mokahr.com/campus-recruitment/moonshot/148507?sourceToken=36ae0fe79b871e0600f2b2cfe0a81ebb#/job/529591c4-cac4-47a1-b122-a15088e5459e

职位描述
就像两百多年前蒸汽机取代人类推动工业生产、近一百年来计算机帮助人类进行信息处理一样，我们相信 AI Agent 最终将会自动化人类的广泛生产性工作。而在当下，作为这场 AI 生产力革命的重要阶段，Agent 正在加速落地、重塑流程与协作方式。加入我们，一起推动这场变革！

你将亲手打造
Kimi CLI 内核、产品及相关工具
Agent 运行基础设施，包括 AI SDK、Agent SDK 和沙箱
Agent 实验平台
下一代 Agent 生产力提升的本质解

我们希望你
不墨守陈规
是 one of "the crazy ones, the misfits, the rebels, the troublemakers, the round pegs in the square holes, the ones who see things differently"
敢于质疑权威，敢于引领而非跟随
Strong opinions, weakly held
有品味
不满足于仅仅编写能跑的代码
对代码、文档、产品的美感有追求
加分项：有精心维护的、你不断觉得它变成屎山然后重构/重写了的项目
知其所以然
不要说你会什么编程语言，你应该"可以"会所有语言
不背八股，而是在实践中理解计算机系统的本质
加分项：精通 Python、TypeScript 或 Rust 中的有趣细节
加分项：能够说出任意软件的任意操作的全链路过程并根据需要无限细化
高强度使用 AI
能够用最少的精力进行任务分发和成果验收
能够判断 AI 的产出质量
加分项：能够锐评各主流大模型和 Agent 产品的调性
可以在面试时直接 show off 你的项目、代码、技术博客和上述加分项的内容

链接: https://app.mokahr.com/campus-recruitment/moonshot/148507?sourceToken=36ae0fe79b871e0600f2b2cfe0a81ebb#/job/4621a0bb-0317-4b68-9971-08960a068149

职位描述:
研究基于Long CoT的大模型强化学习相关技术，包括算法或系统，实现技术突破，涉及：
方向一：推理能力Reasoning
方向二：智能体Agent
以及研究其他通往AGI/ASI的前沿技术

任职要求：
985/211高校研究生以上学历或优秀本科生，计算机科学、人工智能、机器学习等相关专业；
熟悉强化学习和大模型相关技术，具有相关实践和研究经验的同学为佳。
有大模型infra相关研发经验者优先。
有大模型+Agent相关研发经验者优先。
有一定的相关研究经历，发表过顶级会议论文者优先，如ICLR, NeuriPS, CoRL, ICML, CVPR等等；
具备扎实的Python编程基础，有优秀的工程能力，具有ACM等编程竞赛获奖者优先。
具备良好的团队协作能力和沟通能力；

我们是一家以实现 AGI 为目标的 AI 初创公司，正在寻找有技术、有热情的工程师加入我们的产品研发团队。

具体职责 What You Will Do
我们工作地点在北京，主要开发语言为 Go。根据您的能力与偏好，您将负责以下一个或多个方向的工作：
设计与开发主线产品如 Kimi AI 助手的关键特性，关注业务数据与指标，打磨模型效果与用户体验。
AI Agent 研发：探索不同的应用方向与产品形态，最大化释放模型能力，加速模型演进。

强大的代码工程能力和技术热情！

熟练使用 Linux，熟悉 Docker, Kubernetes 等容器技术的使用，理解其原理。有一定的 Golang 开发经验是加分项。
拥有计算机科学的专业背景或同等经验。具备良好的英文阅读与书写能力，拥有检索英文资料、阅读英文技术文档、参与技术社区讨论的习惯。

我们的偏好 Preferred Qualifications
可以使用 Python 或 TypeScript 快速创建原型产品。
自我驱动，探究技术本质，保持学习，乐于分享。
参与过 AI 应用的设计或研发。
