岗位1: AI Agent工程实习生（美术应用平台）| 广州 | 实习

链接: https://hr.163.com/job-detail.html?id=76748

职位描述
1. 负责 AI 美术资产平台相关功能的开发、代码巡检与问题排查，定位并修复功能运行、接口对接、画布交互、客户端工具等环节出现的代码 Bug。
2. 协助维护公司内外部 AI 工具接口的连通性与稳定性，保障 AI 生成美术资产流程顺畅运行。
3. 配合美术团队理解游戏项目需求，参与平台功能开发与迭代，包括但不限于参数配置、美术资产筛选、批量生成、格式转换、项目定制化小工具、画布节点和工作流交互等。
4. 根据个人能力和项目需要，参与前端页面、交互工具、画布/客户端功能、后端接口、任务流程或完整功能闭环的开发与联调。
5. 在 AI 生成代码的基础上，完成代码阅读、验证、调整、联调与测试，确保新功能可正常使用，并处理常见异常情况。
6. 根据游戏项目特性和美术生产需求，对平台现有功能进行简单优化、迭代与适配，提升美术同学的使用体验与工作效率。
7. 协助完成平台日常测试、版本更新、功能验收与问题记录，保障 AI 美术资产能力在项目中的稳定落地。

职位要求
1. 在校大学生，计算机、软件工程、网络工程、数字媒体技术等相关专业，有扎实编程基础。
2. 前端、后端或全栈方向均可，能够看懂、修改和调试基础代码，具备完成简单功能开发的能力。
3. 了解接口调用、网络请求、文件处理、数据交互、页面交互或工具开发等相关基础知识，有项目开发和联调经验者优先。
4. 对画布交互、客户端工具、自动化脚本、AI 工具调用、美术素材处理或游戏开发相关内容有了解者优先，但非硬性要求。
5. 具备基础排错、调试能力，能够独立定位并解决简单代码问题。
6. 学习能力强，沟通顺畅，能配合美术团队理解业务场景，接受游戏行业工作节奏。
7. 态度认真细心，有责任心，愿意接触 AI + 美术跨界业务，有无游戏行业经验均可。

链接: https://hr.163.com/job-detail.html?id=77418

• 具备良好的沟通能力，自我驱动力，能够不断学习和掌握新技术。

岗位3: 大模型算法实习生 | 北京 | 实习

链接: https://hr.163.com/job-detail.html?id=65260

职位描述
参与前沿大模型算法的研发与落地应用，方向包括但不限于：智能 Agent、Deep Research、多模态大模型、检索增强生成 (RAG) 等；
紧跟领域最新技术动态，探索创新算法方法，并积极推动科研成果的产出；
参与技术方案讨论、算法设计与实现、模型训练与优化等研发工作，保证项目进度和研发质量；
持续学习和掌握最新的大模型相关技术，并应用于实际产品和项目中，解决实际问题。

职位要求
硕士及以上学历，计算机、人工智能、自然语言处理、机器学习等相关专业优先；
具备优秀的动手能力，熟练掌握 Linux 环境下的 Python/PyTorch 开发，代码风格规范；
拥有扎实的算法理论基础和丰富的算法研发经验，对大模型及相关领域算法有深入研究和理解；
具备高度的责任心和自驱力，优秀的沟通能力和团队协作精神，能够积极推动项目落地；
具备以下经验者优先：
智能 Agent 相关项目经验，了解 Agent 的核心思想和常用框架，有 Agent 搭建或应用经验；
RAG (检索增强生成) 相关实习或研究经历，熟悉 RAG 流程的各个环节，包括文档解析、向量检索等；
大模型训练、微调、评测经验，熟悉常用的大模型训练框架和优化方法；
多模态文档识别与理解经验，熟悉 OCR、版面分析、信息抽取等技术，有处理复杂文档的经验。
我们希望你：
对大模型技术充满热情，渴望探索前沿算法并将其应用于实际场景；
具备优秀的学习能力和解决问题的能力，能够快速适应新的技术和挑战；
乐于分享和交流，能够积极参与团队合作，共同推动技术创新。

岗位4: Codewave-服务端开发实习生 | 杭州（网易游戏伏羲）| 实习

链接: https://hr.163.com/job-detail.html?id=77843

职位描述
1. Agent 可观测性测试与链路验证 - 参与构建 Codewave AI harness 的可观测性测试体系，覆盖 Agent 执行轨迹、工具调用、阶段编排、token 消耗等关键节点的埋点完整性与准确性验证 - 设计并执行 trace / metric / log 链路的质量校验用例，定位埋点缺陷、链路断点与异常行为，推动可观测性建设闭环
2. 评估数据集构造与治理 - 根据评测场景，构造结构化与非结构化测试数据集（代码、规格文档、对话历史、Agent 产出物、对抗性输入等），覆盖正常、边界与困难场景 - 维护评估数据的版本化与可追溯性，沉淀可复用的数据构造脚本与工具，建立"golden set"评测基线
3. AI 产出的人工评估与标注闭环 - 对 LLM / Agent 的输出（代码、文档、执行计划、工具调用序列等）进行人工评估与质量打分，制定评估 rubric（评分准则），建立人审基线 - 参与评估规范的制定与迭代，校准人审与自动化指标（如 LLM-as-a-Judge）的一致性，沉淀标注样本集，支撑自动化评测与回归
4. 评估基础设施与工具链协作 - 协助完善评估平台、数据管理与可观测性工具链，提升评测构造与标注的效率 - 将测试与评估中发现的问题转化为可执行的诊断（失败模式归类、根因定位），反向驱动 Agent 与 harness 迭代

职位要求
1. 计算机科学、软件工程、人工智能专业本科及以上学历
2. 熟练掌握 Java / Python / TypeScript 任一语言，具备扎实的编程基础与脚本编写能力
3. 熟悉 Linux 常用命令，熟悉基本的数据结构与算法
加分项：
1. 了解 LLM / Agent / RAG 相关概念，对 tool use、prompt engineering、Agent 编排（如 harness、planning）有学习或实践经历
2. 了解可观测性相关概念（分布式追踪 trace、metric、log，或 OpenTelemetry 等）
3. 有软件测试、数据标注、评测或测试开发相关经验，对数据质量与评估方法论有兴趣
4. 有AI编程工具实践
