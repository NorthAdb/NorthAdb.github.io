二、总体战略

定位选择（三选一，建议 A）

  • A. AI 应用/Agent 工程 + 后端复合（推荐）：匹配度最高、岗位量最大、2028 届可投机会最多（字节日常实习、美团日常实习、快手日常实习、米哈游 2028 实习等）
  • B. 纯后端（Java/Go）：岗位多但竞争激烈，且大厂 JD 全部要求"会用 AI 工具"，纯后端无差异化
  • C. 算法/基模方向：需顶会论文/竞赛奖，2028 届硕士时间紧张，作为加分而非主线

时间窗口

时间 事件

2026.09 起 日常实习随时可投（字节/美团/百度/快手/滴滴常年开放，面向全体在校生）
2027.03 - 04 暑期实习集中投递期（2027 届暑期实习通常提前 1 年开放，2028 届的暑期实习 2027 年春开放）
2027.05 - 09 暑期实习
2027.09 起 2028 届秋招提前批

三条主线

  1. 笔试过关：数据结构 + 算法刷题（大厂第一关，26/117 份 JD 明确要求）
  2. 项目可展示：1 个端到端 Agent 项目（GitHub 开源 + 真实 PR，回应"不是 star 收藏家"）
  3. 工具熟练度：Cursor/Claude Code 达到"重度用户"水平（拼多多/阿里/京东/OPPO/米哈游 5+ 份 JD 原话要求）

三、六大学习模块

模块 0：编程底座（贯穿全程，优先级 ★★★★★）

JD 证据：26 份提数据结构/算法，24 份提操作系统；拼多多"编程底子厚"、快手"扎实的计算机基础"、腾讯"专业软件知识，包括算法、操作系统、软件工程、设计模式、数据结构、数据库系统、网络安全"。

行动项： - 主力语言策略（关键）：市场语言分布 = Python 72 次（AI/算法岗第一）· Java 47 次（后端岗主流）· Go 37 次（后端岗主流）。"AI 应用岗看 Python，纯后端岗看 Java/Go"——走复合路线的你两手都要硬： - Python：AI 应用/Agent 项目的主力（模块 1/2 全部用它） - Java 或 Go 二选一：后端岗的敲门砖。腾讯/京东/百度/B站/小红书/OPPO/vivo 后端岗全部点名 Java/Go；你是 Java 基础，保留 Java 并做一个 Java 后端项目（Spring Boot + MySQL + Redis + 消息队列），对标百度 AI 开放平台岗（明确要求"熟练掌握 Java，理解 JVM、并发编程、集合框架"） - 每日 30-60 分钟算法题（LeetCode Hot 100 + 剑指 Offer 为主，目标面试前 300 题量） - 补计算机基础：操作系统（进程/线程/内存）、网络（TCP/IP/HTTP）、数据库（MySQL + SQL）

产出物：无（这是门槛不是亮点）

时间投入：每天 1-1.5h，贯穿到 2027.03

模块 1：LLM 应用开发（优先级 ★★★★★，2-3 个月）

JD 证据：RAG 33 次、Prompt 19 次、工具调用、Context Engineering（淘天/阿里）；百度"大模型应用/agent算法工程师"要求"router分流策略、plan策略、检索rag策略、内容生成质量、工具调用/Deep Research skill效果优化"；阿里"理解短期记忆、中期压缩、长期持久化记忆等 Agent 记忆机制"。

行动项（按顺序）： 1. LLM 原理深化：从"会调 API"到"懂原理"——Transformer 结构、注意力机制、KV Cache、上下文窗口限制（你在学的 LLM 基础继续深化） 2. RAG 全链路（不是"会用"，是"能讲清楚发展、适用场景、受限场景"——阿里原话）：文档解析 → 切分 → Embedding → 向量检索 → 重排 → 答案生成 → 效果评估。落地一个知识库项目 3. Prompt/Context Engineering：系统提示词设计、少样本、结构化输出、上下文压缩/管理 4. Function Calling / Tool Calling：从 API 层理解工具调用的协议机制（tool schema、参数校验、结果回传、异常处理）

学习资源：你在学的 Datawhale LLM 教程 + All-in-RAG 继续；LangChain 官方文档；《Prompt Engineering Guide》

产出物：一个带 RAG 的问答系统（GitHub 开源）

模块 2：Agent 工程（优先级 ★★★★★，你的主攻方向，2-4 个月）

JD 证据：Agent 295 次全场第一；MCP 15 次、Harness 11 次、Skills 7 次、多智能体 20 次、记忆 32 次；字节"多Agent协作、记忆、知识、鉴权、观测全生命周期"；美团"LangGraph、Swarm 框架 + MCP 协议及工具生态"；阿里"MCP、Function Call 开发/集成经验"；小米"Harness优化、评估器优化"。

行动项（按顺序）： 1. 框架实操：LangChain/LangGraph 精熟一个（8+3 次点名），旁通 AutoGen/CrewAI（多智能体 20 次）；Dify 会用（低代码交付岗 1 次，但验证思路快） 2. MCP 协议吃透（15 次点名）：理解 MCP 的 server/client 架构，自己写 2-3 个 MCP server（把你在用的工具封装成 MCP） 3. Skills/Harness 工程（11+7 次）：把业务能力抽象封装为可复用的 Skill——这正是你在学的方向！用你现有的 Harness 学习继续，落地一个"Agent 干活"的真实工作流 4. Agent 记忆（32 次）：短期/长期记忆、记忆检索、压缩；参考小米"快慢双系统记忆架构"、阿里"短期记忆、中期压缩、长期持久化" 5. 多智能体协作（20 次）：多 Agent 分工/协商/编排 6. Agent 评测（76 次，超高频）：评测体系是 2027 市场的独立岗位方向——学评测方法论（成功率/延迟/Token 消耗/工具调用准确率），给你的 Agent 项目搭评测闭环。字节 Agent 评测实习生、MiniMax 大模型算法评测实习生都是可直接投的岗 7. Agent 安全基础（可选）：注入攻击、越权、记忆污染（阿里有 Agent 安全评测实习岗）

学习资源：你的 Harness 学习资料（walkinglabs harness engineering）+ Anthropic Agent 教程 + LangGraph 官方教程 + MCP 官方文档

产出物（这个模块的产出就是简历核心）： - 一个端到端 Agent 项目：真实解决一个问题（如"GitHub Issue 自动处理 Agent"或"论文阅读综述 Agent"），含记忆、工具调用、评测闭环 - 2-3 个 MCP server（开源） - 项目评测报告（展示"评测驱动迭代"能力）

模块 3：AI 工具链与研发范式（优先级 ★★★★，1 个月养成习惯）

JD 证据：Cursor 12 + Claude Code 12 + Codex 9 + Copilot 7 = 40+ 次；OPPO"必须熟练使用 Claude Code、Codex、Gemini CLI 等任一命令行代码助手，维护过 Rules、MCP，熟悉 Agent Skills"；京东"熟练使用 Claude Code、GitHub Copilot、Cursor 等，并对 OpenClaw、Hermes 等 Agent 编排架构有初步理解"；拼多多"熟练使用 Cursor、Claude Code 等AI编程工具提效"。

行动项： 1. 主工具选定：Claude Code / Codex / Cursor 三选一作为日常主力（你在用 opencode，能力等价，保持即可） 2. 熟练度标准：70% 样板代码交给 AI（智谱原话）；能判断 AI 产出质量、能纠错（月之暗面"能够判断 AI 的产出质量"） 3. 研发范式：理解 Vibe Coding 与 Spec Coding/SDD 的区别（OPPO JD 原话），用 SDD 流程做一个完整项目 4. Rules/AGENTS 文件维护：学会为自己的项目写 AI 规则文件（OPPO 明确要求"维护过 Rules"）

产出物：SDD 流程 + AI 工具完成的完整项目（与模块 2 的项目合并）

模块 4：后端工程补强（优先级 ★★★★，复合岗差异化，2-3 个月）

JD 证据：分布式/高并发 43 次、MySQL 10 次、微服务 5 次、K8s 5 次；快手"高并发、海量数据的工程挑战"；小红书"分布式存储、计算、消息队列（Kafka/RocketMQ）、微服务治理"；拼多多"缓存机制、消息队列、异步调度"。

行动项： 1. 中间件认知：Redis（缓存）、Kafka/RocketMQ（消息）、MySQL（调优）——达到"能说原理、会选型"（百度 JD"熟悉MySQL调优技巧"） 2. 分布式基础：一致性、负载均衡、限流熔断、高可用设计 3. 容器化：Docker + K8s 基础（5 次点名） 4. 工程实践：把模块 2 的 Agent 项目做成高可用服务：API 网关、鉴权、限流、日志监控、可观测性（对应百度 AI 开放平台岗的要求）

产出物：Agent 项目后端工程化（接口设计、部署、监控）

模块 5：开源与简历资产（优先级 ★★★★，贯穿）

JD 证据：开源贡献 48 次、GitHub 11 次；阿里"开源项目的核心贡献者（不是 star 收藏家，是真的提过 PR）"；月之暗面"有精心维护的、你不断觉得它变成屎山然后重构/重写了的项目"；京东"核心开源AI项目有代码贡献"。

行动项： 1. 主项目开源：模块 2 的 Agent 项目做成精品开源项目（README、文档、示例、CI） 2. 真实 PR：给 2-3 个活跃开源项目提 PR（你熟悉的：OpenClaw、LangChain、MCP 生态、Datawhale 教程仓库）——从文档修复/小 bug 开始 3. 技术博客：3-5 篇高质量文章（"如何用 MCP 封装 XX 工具"、"我的 Agent 项目踩坑记"）——京东/商汤/月之暗面 JD 都提博客加分 4. 竞赛（可选）：Kaggle 或天池入门赛一次（8 次点名）

进阶模块（可选，按精力）：模型微调与 RL

JD 证据：SFT 22、RLHF 12、GRPO 10、RLVR/Agentic RL 8、LoRA 3；美团"多轮RL、Agentic RL"优先；快手"RLHF/RLVR 经验优先"。

行动项： 1. LoRA 微调一个开源小模型（Qwen2.5-7B 级别）做领域适配（携程/汇锐 JD 点名） 2. 理解 SFT/RLHF/DPO/GRPO 流程（跟一遍现有教程，不追求独立实现） 3. 若学有余力：Agentic RL（环境、轨迹收集、Reward 设计）——这是 2027 最前沿，但投入产出比低，建议仅了解

七、关键提醒

  4. 你的独有优势：你已经在学 Harness 工程 + 玩 OpenClaw——这恰好是京东/OPPO/阿里 JD 点名的技能，市场窗口期内是稀缺卖点，务必转化为可展示项目
