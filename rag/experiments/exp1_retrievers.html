实验 1：检索器对比（Dense / BM25 / Hybrid）

生成时间：2026-09-12 20:58（本机真实运行）

主语料 strategy=flat500x80，20 道可回答题 + 5 道不可回答题（不可回答题不计入召回指标）。

方案 recall@5 mrr@5 noise@5 kw_hit@3 kw_hit@5 seconds
Dense 1.0 0.88 0.571 1.0 1.0 2.5
BM25 0.957 0.808 0.614 0.929 1.0 0.8
Hybrid(RRF) 1.0 0.928 0.557 1.0 1.0 0.2
Hybrid(加权-错) 1.0 0.822 0.6 1.0 1.0 0.2
Hybrid(归一加权) 1.0 0.884 0.543 1.0 1.0 0.2
Hybrid(RRF)+Rerank 1.0 0.928 0.557 1.0 1.0 13.8

要点：

  • Dense 擅长语义改写题，对精确符号题（STTNI、VPGATHERDD）偏弱；
  • BM25 反之：符号题一打一个准，语义改写题丢分；
  • Hybrid(RRF) 应不低于两路中较弱的一路；
  • Hybrid(加权-错) 会被 BM25 的无界分数绑架，名次几乎等于 BM25 单路 —— 这就是不能直接加分数的证据；
  • +Rerank 在本语料上 MRR 未变（Top-1 已基本正确）而耗时显著增加 —— “收益必须实测”的活例子；候选更杂、语料更大时 rerank 的价值才会显现（第 7 节有逐题对比）。
