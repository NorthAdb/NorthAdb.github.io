Linux 排查 · 一页速查

CI / SDET 笔试够用版。细节见同目录分册。

AI AI Agent 面试宝典 CI/CD 面试突击 阅读约 2 分钟
On this page

CI / SDET 笔试够用版。细节见同目录分册。

1. 进程排查

ps aux | grep -i [j]enkins          # 找进程（方括号防匹配自身）
ps -ef --forest                      # 看父子树
pgrep -af pytest                     # 按名找
top -o %CPU                          # CPU 排行；htop 更友好
pidstat -u 1 5                       # 某进程 CPU（sysstat）
lsof -p <pid>                        # 打开的文件 / 端口
cat /proc/<pid>/status | head        # 状态、VmRSS
kill -15 <pid>                       # 优雅退出；不行再用 -9

僵死：STAT=Z → 查父进程，杀/重启父进程才能收尸。

2. 网络调试

ss -lntp                             # 谁在听端口（替代 netstat）
ss -antp | grep ESTAB                # 已建立连接
curl -vI https://example.com         # HTTP 头 + TLS 握手
ping -c3 8.8.8.8                     # 三层通不通
dig +short gitlab.example.com        # DNS
ip route | head                      # 默认路由
tcpdump -i any port 443 -nn -c 20    # 抓 20 包（需权限）

通路由、不通业务：先 ss/curl -v，再看防火墙 iptables -L -n / nft list ruleset。

3. 权限

ls -l file                           # -rwxr-xr-x → u/g/o
stat -c '%a %U:%G %n' file           # 755 user:group
chmod u+x script.sh                  # 加执行
chmod 640 secret.env                 # 属主读写、组读
chown user:group path
sudo -u runner ./job.sh              # 指定用户跑
id; groups                           # 当前身份
getfacl file                         # ACL（若启用）

Permission denied：先看属主/位，再看目录执行位 x，再看 SELinux/AppArmor。

4. Core dump

ulimit -c                            # 0 = 不落盘；unlimited 打开
ulimit -c unlimited
cat /proc/sys/kernel/core_pattern    # 落盘路径模板
# 崩了之后：
gdb ./app core                       # 或 core.<pid>
bt                                   # gdb 里看堆栈

容器里常默认禁 core；CI 要复现崩溃需显式开 ulimit + 挂卷。

5. 日志分析

journalctl -u gitlab-runner -n 100   # 服务最近日志
journalctl --since "1 hour ago" -p err
tail -F /var/log/syslog              # 跟随
dmesg -T | tail                      # 内核
grep -E 'ERROR|FATAL' app.log | tail

应用 JSONL / 文本日志 → 用 01-basic-shell / 02-log-python。

6. 后台任务

cmd &                                # 后台，关终端可能死
nohup cmd >out.log 2>&1 &            # 忽略挂断 + 重定向
jobs -l; fg %1; bg %1                # 作业控制
disown %1                            # 从 shell 作业表摘掉
screen -S build / tmux new -s build  # 可重连会话
systemd-run --user --unit=job cmd    # 临时单元（有 systemd）

长期任务优先 systemd / CI Job，少靠裸 nohup 堆在登录机。
