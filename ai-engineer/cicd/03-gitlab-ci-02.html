2. 必须掌握语法（六个关键字）

面试听到关键字，要能立刻说「干什么用」。

AI AI Agent 面试宝典 CI/CD 面试突击 阅读约 2 分钟
On this page

面试听到关键字，要能立刻说「干什么用」。

速查表

关键字 作用 一句话
stages 定义执行顺序 先声明阶段名，Job 挂到阶段上
script 执行命令 Job 的真正干活内容
rules 控制触发 什么事件才跑这个 Job
cache 缓存依赖 / 中间文件 加速后续流水线
artifacts 保存构建产物 / 报告 可下载、可给后续 Job
needs Job 依赖 / 并行 缩短总时长，不必死等整个 stage

1）stages + script

stages:
  - lint
  - test
  - build

unit_test:
  stage: test
  script:
    - pip install -r requirements.txt
    - pytest tests/smoke -m smoke

要点：

  • 未写 stage 的 Job 默认进 test（了解即可）
  • script 任一行非 0 退出 → Job 失败 → 门禁变红

2）rules（多门禁灵魂）

mr_smoke:
  rules:
    - if: $CI_PIPELINE_SOURCE == "merge_request_event"
  script:
    - pytest tests/smoke -m smoke

gate1:
  rules:
    - if: $CI_COMMIT_BRANCH == "main" && $CI_PIPELINE_SOURCE == "push"
  script:
    - pytest tests/gate1 -m gate1

daily:
  rules:
    - if: $CI_PIPELINE_SOURCE == "schedule"
  script:
    - pytest tests/full

release:
  rules:
    - if: $CI_COMMIT_TAG
  script:
    - ./build_release.sh
    - pytest tests/release -m release
场景 常见条件
MR merge_request_event
合入主干后 main + push
Daily schedule
发版 $CI_COMMIT_TAG
手动 when: manual

3）cache vs artifacts（极易混，必背）

Cache Artifacts
目的 加速本次 / 后续流水线 保存输出产物
典型内容 pip 包、.venv、编译中间文件 程序包、镜像、JUnit 报告
用途 临时缓存，提升速度 可下载，供后续 Job / 人使用 
test_job:
  cache:
    key: pip-$CI_COMMIT_REF_SLUG
    paths:
      - .cache/pip
  script:
    - pip install -r requirements.txt
    - pytest --junitxml=report.xml
  artifacts:
    when: always          # 失败也归档报告，方便排查
    paths:
      - report.xml
    reports:
      junit: report.xml

口述：

「Cache 是为了下次跑得快；Artifacts 是要把产物留下来给人看或给下一 Job 用。」

4）needs：并行与依赖

默认：同一 Stage 内可并行，下一 Stage 等上一 Stage 全完。
needs：可以跨 Stage 指定「我只等某几个 Job」，总时长更短。

lint:
  stage: lint
  script: [ruff check .]

unit:
  stage: test
  needs: [lint]          # lint 完立刻开测，不必等 lint stage 里其他无关 Job
  script: [pytest tests/smoke -m smoke]

build:
  stage: build
  needs: [unit]
  script: [./build.sh]

面试说法：「用 needs 把关键路径串起来，避免无依赖的 Job 互相拖时间。」

记忆口诀

stages 排顺序，script 真干活，rules 控开关，cache 提速度，artifacts 留产物，needs 削等待。
