目录 主题

闭环示意

请求 → route.decision → breaker.allow?
         ↓ 否 → fallback → billing
         ↓ 是 → retry + llm.chat
              ↓ 失败 → fallback → billing
              ↓ 成功 → billing

cd 05-model-route/05 && python main.py
cd 05-model-route/06 && python main.py
cd 05-model-route/04 && pytest -v
