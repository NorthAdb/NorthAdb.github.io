拆解 Claude 官网的设计语言

2025 年 7 月 18 日 阅读约 7 分钟

在过去很长一段时间里，AI 产品的界面总是逃不开两种命运：要么是聊天框加按钮的「功能面板」，要么是霓虹渐变堆满的「赛博朋克」。直到 Claude 出现，它提供了一个完全不同的答案——一家 AI 公司的官网，居然可以像一本装帧考究的书。

这篇文章想拆开看看：Claude 官网（以及整个 Anthropic 的品牌）到底做对了什么？而我们——包括我这个博客——又能从中学到什么？

一、色彩：把克制做到极致

打开 claude.ai，你的眼睛首先接触到的是一大片近黑底色。这不是纯黑 #000000，而是一种带暖调的深色——官方称之为「Cream」体系下的暗色变体，介于 #0F0F0F 与 #1A1918 之间。

它选了一个极为克制的强调色：珊瑚橙（Coral），大约 #D97757。这个颜色妙在哪里？

  • 它有温度——不像蓝紫色那么「科技」，也不像正红色那么有攻击性
  • 它与近黑底色形成恰到好处的对比，不刺眼，但足够醒目
  • 它让人想起日落、陶土、篝火——一种「有机」的质感，暗合 Anthropic「AI 应更人性化」的主张

整个品牌色板里，珊瑚橙几乎只用于「需要被注意」的地方：主按钮、链接、logo 点缀。其余全部让位给黑白灰。用最少的颜色，说最清楚的话。

二、字体：衬线体回归

Claude 官网最显著的特征，是标题使用了衬线字体（Copernicus）——带衬线的笔画在近黑背景上展开，像烫金的铅字。正文则使用无衬线的 Styrene 字体，保证长文阅读的舒适。

这种「衬线标题 + 无衬线正文」的搭配在今天的科技界几乎是异类。大多数产品为了「现代感」清一色使用无衬线，结果就是千篇一律的「硅谷模板」。Claude 反其道而行，用衬线体传达三个信息：

  1. 文化感——文字是思想的载体，衬线体天然带书卷气
  2. 辨识度——在一众无衬线的竞品中一眼可辨
  3. 时间感——它提醒你，这家公司相信「深思熟虑」的价值

顺带一提，本博客的标题字体同样采用了衬线栈（Georgia → 宋体），正是出于同样的考量。

三、纹理：看不见的细节

如果你仔细看 Claude 的页面背景，会发现它并不是纯色，而是铺着一层极淡的点状网格。这种纹理有多淡？淡到大多数用户根本不会注意到——但它恰恰是「高级感」的来源。

纯色背景是「平面」，带纹理的背景是「纸面」。人的视觉系统对微妙的材质差异极其敏感：

细节不会让你尖叫「哇」，但它的缺失会让你嘀咕「哪里不对」。

实现这种纹理只需要几行 CSS：

body::before {
  content: "";
  position: fixed;
  inset: 0;
  background-image: radial-gradient(
    rgba(255, 255, 255, 0.05) 1px,
    transparent 1px
  );
  background-size: 26px 26px;
  z-index: -1;
}

成本几乎为零，质感立竿见影。

四、留白：让内容呼吸

Claude 官网的信息密度极低。大标题和正文之间有巨大的空隙，卡片与卡片之间保持克制的间距，导航栏简单到只有几个词。这看起来「浪费」，其实是深思熟虑：

  • AI 产品的用户正在处理复杂的认知任务，界面应当减少干扰
  • 留白让核心信息（对话、代码、文字）成为唯一的主角
  • 高级感 = 自信。敢于留白，说明内容本身足够有分量

对比那些把按钮、弹窗、横幅塞满首屏的产品，Claude 的选择是一种宣言：我们相信用户是来工作的，不是来逛商场的。

五、我们学到了什么

这套设计语言对我的博客改版产生了直接影响，总结成三条可迁移的原则：

  1. 先定调色板，再写样式——把背景、文字、强调色三个变量定义成 CSS 自定义属性，全局的一致性就有了锚点
  2. 克制地使用强调色——珊瑚橙只出现在交互点和视觉锚点上，用量 ≤5%
  3. 纹理与留白是免费的奢侈品——几行 CSS 的点阵、足够的 padding，比任何花哨组件都更能塑造气质

好的设计从来不是「加」出来的，而是「减」出来的。Claude 官网告诉我们：当一家公司足够相信自己的产品，它的界面就会安静下来。

而这，大概也是我想让这个博客成为的样子。
