一句话总结

Pi = 极简编码 Agent 线束（harness）：内核做「多模型 LLM + Agent 循环 + JSONL 会话 + 默认四个工具 + 终端 UX」。MCP 与 codemode 是可替换的内置扩展。其余工作流靠 Extensions / Skills / Packages / SDK 自己拼。改工作流，不必改循环。
