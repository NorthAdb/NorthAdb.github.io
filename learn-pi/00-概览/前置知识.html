前置知识

按目标分档：不必一次全会。

A. 只用 Pi 当编码助手（最低）

  • 会用终端（PowerShell / bash）
  • 会装 Node（本仓库要求 Node ≥ 22.19；部分依赖提示更高）
  • 有一家模型的 API Key，或可用的订阅（/login）
  • 基本 Git 概念（会话与项目目录相关）

不需要：写 TypeScript、懂 monorepo、懂 Agent 循环。

路径：官方 quickstart + 本系列 本地跑起来.md。

B. 写 Skill / Prompt Template / Theme（低）

  • Markdown 与 YAML frontmatter
  • 会把文件放到 ~/.pi/agent/ 或项目 .pi/ 约定目录
  • 理解「系统提示里只有摘要，完整技能按需加载」（渐进披露）

路径：packages/coding-agent/docs/skills.md、prompt-templates.md、themes.md。

C. 写 Extension / 二次定制工作流（中）

必备：

  • TypeScript / JavaScript（async/await、模块、基本类型）
  • 阅读别人的 TS 例子并改
  • 理解「工具 = 名称 + JSON schema + execute 函数」

加分：

  • Node 文件系统与子进程
  • 终端 UI 基础（若要做自定义组件）
  • 对 LLM tool calling 有直觉（模型返回 tool_use，宿主执行再把结果喂回）

路径：examples/extensions/hello.ts → permission-gate.ts → docs/extensions.md。

D. 用 SDK / RPC 嵌入自己的应用（中高）

  • Node 应用结构、事件流 / JSONL
  • 进程间通信（RPC 模式）
  • 错误处理与取消（AbortSignal）

路径：examples/sdk/01-minimal.ts → 12-full-control.ts，docs/sdk.md、docs/rpc.md。

E. 改内核 / 跟进 Harness 设计（高）

  • 扎实 TS（含泛型、声明合并）
  • 并发与可重入（hooks、busy phase、pending writes）
  • 持久化与会话树（append-only log、leaf、compaction）
  • 愿意读长设计文档：先 packages/agent/README.md，再 packages/durable/docs/spec.md（实验，API 会变）

推荐补课清单（按缺口）

缺口 补什么
不懂 LLM 工具调用 任意一篇 OpenAI/Anthropic tool use 教程 + 看 packages/agent/README.md 事件序列图
不懂 monorepo 本系列 包地图与依赖.md
不懂流式输出 跑 SDK 最小例子，订阅 message_update
不懂终端原始模式 packages/tui/README.md 前几节即可，不必先精通
网络/代理问题 本机 HTTP(S)_PROXY；模型目录生成依赖 models.dev（见本地构建笔记）

时间预期（粗估）

目标 时间
跑起来并完成一次改文件任务 0.5–1 天
写第一个 skill / prompt 几小时
写第一个有用的 extension 1–3 天
读懂 agent-loop + AgentSession 1–2 周（业余）
能基于 SDK 做小产品 数周

学习时建议准备的环境

  1. 已 clone 的本仓库 + npm install --ignore-scripts + 成功 build（或 hydrate:model-data + build:offline）
  2. 至少一个可用模型（国内网络注意代理）
  3. 编辑器能跳转 TypeScript 定义（Cursor / VS Code）
  4. 可选：tmux（官方推荐用 tmux 代替「后台 bash」心智）
