术语表

术语 含义
Pi 通常指 coding-agent 产品 / CLI；广义指整个 harness monorepo
Harness 把模型、工具、会话、扩展绑在一起的编排层
Agent loop 多轮「LLM → 工具 → LLM」循环
AgentMessage 应用侧消息（可含自定义类型）
convertToLlm 把 AgentMessage 投影为模型可读 Message
Tool 名称 + 参数 schema + execute；供模型调用
Extension TS 模块，注册工具/钩子/命令/UI/Provider 等
Skill 按需加载的能力说明包（Agent Skills）
Prompt template slash 展开的提示模板
Pi Package 可安装的扩展资源捆
Theme 终端主题
ResourceLoader 发现并加载上述资源的组件
AgentSession coding-agent 产品级会话门面
Mode interactive / print / json / rpc 等 I/O 形态
SDK 嵌入 Node 应用的库 API
RPC mode JSONL 进程协议模式
Session file 持久化会话（常见 JSONL）
Branching 会话树分叉与导航
Compaction 压缩过长上下文
Steering / Follow-up 运行中插入用户输入的不同队列语义
Scoped models 会话可用模型子集
Provider 模型厂商/网关适配
Faux provider 测试用假模型后端
piConfig 换皮：name / configDir 等
Gondolin 将工具执行放入本地 Linux 微 VM 的隔离模式之一
Progressive disclosure 技能等资源先暴露摘要、按需加载全文
Turn snapshot 单次 LLM turn 的冻结配置视图
Hook 可改变行为的参与者回调（非只读）
Event 只读观察流
MCP Model Context Protocol。Pi 以内置可替换扩展接入，默认 exposure: "codemode"，工具不声明给模型
mcp.json MCP 服务器配置：用户级 ~/.pi/agent/mcp.json + 受信任项目的 .pi/mcp.json
exposure 工具对模型的暴露等级：direct / model-only / codemode / deferred / hidden
codemode 在 QuickJS 沙箱里执行模型写的 JS，唯一能力是调用注入的工具
tool_search 把 deferred 工具按需装载进模型声明的工具
Built-in extension 随 Pi 发布但走扩展 API 的组件（llama.cpp / codemode / tool-search / mcp），可被第三方替换
Virtual model 一个可选条目，把每次请求路由到某个物理模型 + thinking 档
Namespace 工具分组（一个 MCP server 就是一个 namespace），codemode 里按组展示
Nested tool call 工具通过 ctx.executeTool() 调用另一个工具，事件带 parentToolCallId

有歧义时以官方 docs 英文术语为准。
