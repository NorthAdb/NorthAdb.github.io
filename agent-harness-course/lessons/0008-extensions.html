Extensions：Minimal Core 的另一半

Pi 没有把权限确认、自定义命令、本地模型支持写进核心——它留了 40+ 个钩子，让你在外面包一层。这一课看这个"注册面 × 事件面"的架构，以及 Extension 与 Skill 的边界。

本课核心问题：为什么 Pi 不把所有功能直接写进 Core？"Minimal Core + Extensible Harness"为什么是一种设计哲学？Extension 和 Skill 的边界到底在哪？

一、这张图要解决什么问题

任何 Harness 都面临一个拷问：新需求（确认危险命令、接本地模型、自定义面板）来了，是改 Core，还是留接缝？这张图展示 Pi 的答案：一个极小的核心，加上两条扩展通路——注册面（往里放东西）和事件面（在流程上挂钩子）。

二、如何从图上读懂 Pi

源码扩展本体是一个函数。ExtensionFactory = (pi: ExtensionAPI) => void（extensions/types.ts:2004），TS 文件由 jiti 动态加载（loader.ts）。事件类型从 ExtensionEvent（:1364）开始，注册面在 ExtensionAPI（:1551）：registerTool / registerCommand / registerShortcut / registerFlag / registerMessageRenderer / registerProvider / registerMcpServer。事件面包括 session_start / before_agent_start / context / before_provider_request / tool_call / tool_result / agent_start / turn_end / …。

源码钩子的权力有多大？举三个实锤：before_agent_start（:911）可以改写系统提示词；tool_call 处理器返回的 ToolCallEventResult（:1413）带 block?: boolean（:1415），可以拒绝一次工具调用；session_before_compact（:763）可以接管压缩。官方示例 examples/extensions/permission-gate.ts 用扩展实现危险命令确认门——第 9 课会回头讲它。

源码连 provider 和 MCP 都是扩展。随产品加载的内置扩展有四个（src/extensions/index.ts:7-14）：llama.cpp 用 pi.registerProvider() 接本地模型；codemode、tool-search、mcp 标了 replaceable: true，第三方扩展可以整个顶替。"接新模型"和"接工具协议"都不在 Core 里。

Extension ≠ Skill（结合源码说）：permission-gate 是 Extension——它是可执行代码，在运行时拦截 tool_call 事件、弹 UI、返回 block；而 .pi/skills/interactive-testing.md（仓库 AGENTS.md 里自己用到的）是 Skill——它是知识文档，靠模型读 SKILL.md 后自觉遵循。一句话：Skill 改变模型知道什么，Extension 改变 Harness 做什么。

三、新概念的七问：Extension / Hook

  1. 解决什么问题？让千差万别的工作流需求不污染核心——工作流是用户的，接缝才是 Core 的。
  2. 没有它会怎样？Core 膨胀成 if-else 泥潭；每换一个团队/公司都要 fork 整个 Agent。
  3. 输入是什么？一个 TS 文件（factory 函数）+ 用户/项目目录的发现规则。
  4. 输出是什么？注册进核心的能力（工具/命令/UI/provider）+ 挂在事件上的行为。
  5. 由谁控制？事件由核心 emit（runner.ts 分发）；处理器逻辑由扩展作者写；加载受 Project Trust 门禁（第 9 课）。
  6. 和前一概念的关系？Skill 是给模型的知识包（被动、由模型触发）；Extension 是给 Harness 的行为包（主动、由事件驱动）。
  7. Pi 在源码哪里实现？源码packages/coding-agent/src/core/extensions/{types,runner,loader}.ts；例子在 examples/extensions/（80+ 个）。

五、这张图在整个体系中的位置

Extensions 让 Core 敢于保持最小。下一课讨论安全性时你会看到同一个哲学的激进面：连"权限系统"本身也不在 Core 里——它被留给扩展与外部环境。
