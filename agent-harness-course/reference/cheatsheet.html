Agent Harness 课程 · 参考 · 一页纸速查表（打印友好）

整门课程，一页纸

公式（第 14 课）

Agent = Harness( Loop( Runtime( LLM ) ), Environment )
LLM 是被调用的函数；Harness 是拥有控制权的主体。
LLM 对 Environment 没有任何直接通路。

五层模型

层输入→输出谁控制
1 ModelContext → token被调用
2 Loop投影 → 动作/终止Runtime 的 while
3 Runtime调度 → 副作用请求Loop
4 Harness意图 → 配置/约束/界面它拥有系统
5 Environment副作用 → 观察物理世界

Agent Loop 骨架（第 2 课）

while True:                        # 外层 followUp
    while more or pending:         # 内层 toolCall/steering
        ctx = build_projection()
        msg = stream_fn(model, ctx)
        calls = [c for c in msg if c.type=="toolCall"]
        if not calls and not pending: end()
        for c in calls:
            r = hooks.tool_call(c) or validate_execute(c)
            ctx.append(toolResult(r))   # isError 也是消息
