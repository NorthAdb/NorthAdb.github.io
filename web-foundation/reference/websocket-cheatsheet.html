WebSocket 速查表

生命周期

① HTTP 握手：GET /ws/chat HTTP/1.1  +  Upgrade: websocket
② 服务端 accept() → 101 Switching Protocols（此后不再跑 HTTP）
③ 帧往返：receive_* / send_* 任意交错（双向）
④ 探活：Ping 帧 → 对方自动 Pong（协议层心跳）
⑤ 关闭：带状态码 —— 1000 正常 · 1001 对端离开 · 1011 服务器错误

服务端（FastAPI）

from fastapi import FastAPI, WebSocket, WebSocketDisconnect

@app.websocket("/ws/chat")
async def ws_chat(ws: WebSocket):
    await ws.accept()                    # 完成 101 握手（不 accept 可拒绝连接）
    try:
        while True:
            data = await ws.receive_json()   # receive_text/json/bytes
            await ws.send_json({"echo": data})
    except WebSocketDisconnect:           # 客户端断开的唯一正常出口
        manager.disconnect(ws)

# 多连接：ConnectionManager（connect / disconnect / send_personal / broadcast）
# 广播遍历 list(self.active) 快照；死连接 try/except 就地清理

浏览器客户端

const ws = new WebSocket("wss://host/ws/chat");   // 生产用 wss://
ws.onopen = () => ws.send(JSON.stringify({text: "hi"}));
ws.onmessage = (e) => console.log(JSON.parse(e.data));
ws.onclose = (e) => console.log(e.code, e.reason);
// F12 → Network → 选 ws 连接 → Messages 面板：绿↓收帧 橙↑发帧

SSEWebSocket

底层纯 HTTPHTTP Upgrade 换协议
