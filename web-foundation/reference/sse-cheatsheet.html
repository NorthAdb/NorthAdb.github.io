SSE 速查表

报文格式（WHATWG 规范）

: 注释行（客户端忽略，常作心跳）
retry: 3000            # 断线后重连等待（毫秒）
id: 42                 # 事件编号 → 浏览器存为 lastEventId
event: token           # 事件名（缺省 = message）
data: {"text": "检"}   # 载荷（多行 = 多个 data 行）
                       # 空行 = 一条事件结束（漏了不派发！）

服务端（FastAPI 原生）

from fastapi.sse import EventSourceResponse, ServerSentEvent

@app.get("/events", response_class=EventSourceResponse)
async def events():                      # 必须自身是 async generator
    yield ServerSentEvent(event="token", id="1", data={"text": "检"})
    yield ServerSentEvent(event="done", raw_data="[DONE]")
  • 框架自动：text/event-stream 头、no-cache、X-Accel-Buffering: no、15s 空闲心跳
  • data= 会 JSON 编码；raw_data= 原样发送（哨兵值用）
  • 404 等错误语义放 Depends 依赖（响应开始前执行）；generator 内 raise 会掐断已发出的 200 流
  • return EventSourceResponse(gen()) 风格会报错——端点必须 yield

断线续传

浏览器：断线自动重连，带请求头  Last-Event-ID: <最后收到的 id>
服务端：读该头，从事件缓冲补发 seq > id 的事件
@app.get("/events", response_class=EventSourceResponse)
async def events(last_event_id: Annotated[str | None, Header()] = None):
    start = int(last_event_id) + 1 if last_event_id else 1

客户端

const es = new EventSource("/events");   // 仅 GET
es.onmessage = (e) => ...                 // 无名事件
es.addEventListener("token", (e) => ...) // 命名事件必须逐个注册
// e.data / e.lastEventId / es.readyState: 0 CONNECTING 1 OPEN 2 CLOSED
// POST 场景：fetch + ReadableStream 手动按 "\n\n" 分帧解析
