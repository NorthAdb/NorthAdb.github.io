SSE 格式实验室

左边是服务器发往浏览器的原始字节（就是 v3a 里 sse_format() 拼出来的东西）。右边是浏览器 EventSource 解析后派发的事件。改左边的文本，右边实时变化——协议格式从此不用背，动手拆一遍就懂。

解析规则（WHATWG）

  • 以 event: / data: / id: / retry: 开头的行是字段
  • 以 : 开头的行是注释 → 客户端忽略，常作心跳
  • 空行 = 事件结束。没有空行，事件就一直"攒着"不派发（示例 4）
  • 没有 event: 字段 → 事件名是 message（用 onmessage 收）
  • 多个 data: 行 → 用换行符拼接成一条载荷（示例 3）
心跳为什么发 : ping 而不是 data: ping？
