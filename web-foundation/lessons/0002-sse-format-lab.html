解析规则（WHATWG）

  • 以 event: / data: / id: / retry: 开头的行是字段
  • 以 : 开头的行是注释 → 客户端忽略，常作心跳
  • 空行 = 事件结束。没有空行，事件就一直"攒着"不派发（示例 4）
  • 没有 event: 字段 → 事件名是 message（用 onmessage 收）
  • 多个 data: 行 → 用换行符拼接成一条载荷（示例 3）
