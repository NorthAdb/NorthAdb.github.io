全景地图：你的 Agent 在哪里遇见网络

这一课不写代码。目标只有一个：把"你已经会的"和"这门课要教的"放到同一张地图上，以后每一课你都知道自己在哪。

1. 两个世界

你学过的 Agent 基础（loop、tool calling）和 RAG 基础，全部发生在一个 Python 进程内部。它们是发动机。但发动机不会自己变成一辆车——用户要能打开网页提问、要能看着答案一个个字蹦出来、要能在它失控时按下暂停键。这些全是进程之外的事，靠的是网络通信。

已会 · Agent 内部 Agent Loop · Tool Calling · RAG · Memory
↕ 唯一的接口：事件流（Event Stream）——Agent 把"我在检索/我要调工具/这是第 3 个 token"以事件形式吐出来
本课 · 通信层 HTTP → Streaming → SSE → WebSocket（承载者：FastAPI / ASGI）

2. 三个学期的问题，一个直觉

餐厅比喻

普通 HTTP：点菜，厨师做完端上来，你吃完才能点下一道（一问一答）。
SSE：厨师边做边喊"菜洗好了→下锅了→起锅了"（单向直播）。
WebSocket：你和厨师边做边聊："少放辣""好""等等，先别放盐"（双向对话）。

课程结束前，请记住这个判断式：只需要服务器不停地说 → SSE；需要客户端随时插话 → WebSocket；两者都要 → 双通道（毕业实验的做法）。
